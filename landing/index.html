What is Antelope Tools?

Antelope Tools is an open-source network monitor for Antelope blockchains: Vaulta (EOS), Telos, WAX, XPR Network, Libre, FIO and their testnets. It brings block producer, node, endpoint and reward information together in one place. Originally created by Edenia, it is now developed and operated by EOSphere as open infrastructure data for the Antelope ecosystem.

Why is it important?

Antelope networks are run by block producers elected by token holders, and developers and users depend on the infrastructure those producers operate. Antelope Tools shows how each producer and its nodes are performing, so token holders, node operators and developers can make informed decisions based on transparent, reliable data.

Where does the data come from?

Data is read directly from each chain's public system tables and enriched with every block producer's bp.json file and checks of the endpoints they publish. CPU benchmarks come from Hyperion history nodes. Want to dig deeper? The code is open source on GitHub, or join the conversation on Telegram.
